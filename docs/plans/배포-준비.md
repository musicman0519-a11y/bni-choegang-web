## 설계 결정
- 호스팅은 GitHub Pages 유지. 옛 사이트의 서버 렌더는 쓰지 않고, 정적 파일 + Supabase 로 간다.
- anon 키는 공개 키이므로 `supabase-config.js` 에 넣어 커밋한다. service_role 키·Edge Function 비밀값은 저장소에 두지 않는다.
- 관리자 비밀번호는 제가 받지 않는다. 로그인이 필요한 확인은 사용자가 직접 하고, 저는 로그인 없이 되는 부분(공개 읽기, 참관 신청 저장)을 자동 테스트로 증명한다.
- DB 글 본문은 **텍스트 형식**(빈 줄 문단, `##` 소제목, `- ` 목록, `**굵게**`)으로 통일한다. 관리자 편집기가 텍스트 기반이라 HTML 을 DB 에 넣으면 편집 화면에 태그가 그대로 보이기 때문. 대신 사이트 렌더러가 목록·소제목을 지원하도록 보완한다.
- 이메일 확인은 **끈다**(Confirm email off). 관리자 테이블에 등록된 이메일만 가입·로그인되므로 확인 메일 없이도 안전하고, Redirect URL 설정 실수로 막히는 일이 없다.
- Supabase 무료 플랜의 7일 미사용 정지는 GitHub Actions 주간 핑으로 막는다.
