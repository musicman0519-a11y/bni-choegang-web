# 관리자 페이지 설정 안내

관리자 페이지 주소: `admin.html` (예: `https://내도메인/admin.html`)
메뉴에는 링크가 없으니 주소를 직접 입력해 들어갑니다.

## 1. Supabase 프로젝트 만들기 (처음 한 번)

1. https://supabase.com 에 가입 → **New project**
2. 프로젝트 이름: `bni-choegang`, 데이터베이스 비밀번호는 따로 적어 두기, Region: **Northeast Asia (Seoul)**
3. 프로젝트가 만들어질 때까지 1~2분 기다리기

## 2. 데이터베이스 만들기

1. 왼쪽 메뉴 **SQL Editor** → **New query**
2. `supabase/schema.sql` 파일 내용을 전부 붙여넣기
3. **맨 마지막 줄의 `admin@example.com` 을 관리자로 쓸 이메일로 바꾸기**
4. **Run** 클릭 → "Success" 가 나오면 완료

## 3. 관리자 계정 만들기

1. 홈페이지의 `admin.html` 에 들어가서 **'처음이신가요? 계정 만들기'** 클릭
2. 2번에서 적은 것과 **같은 이메일**과 비밀번호(8자 이상) 입력
3. 이메일로 온 확인 링크를 누른 뒤 로그인

> 관리자로 등록되지 않은 이메일은 계정 만들기가 데이터베이스에서 막혀요. 그래서 Supabase 의 **Allow new users to sign up** 설정은 **켜 둔 채로** 두세요.
> 확인 메일 없이 바로 쓰고 싶으면 **Authentication → Sign In / Providers → Email → Confirm email** 을 끄면 됩니다.

## 4. 홈페이지에 연결하기

1. 왼쪽 메뉴 **Project Settings → API** (또는 Data API)
2. **Project URL** 과 **anon public** 키를 복사
3. 홈페이지 폴더의 `supabase-config.js` 에 붙여넣기

```js
window.SUPABASE_URL = "https://xxxxxxxx.supabase.co";
window.SUPABASE_ANON_KEY = "eyJhbGciOi...";
```

> `service_role` 키는 절대 넣지 마세요. anon 키는 공개돼도 괜찮은 키이고, 데이터는 2번의 보안 규칙으로 보호됩니다.

## 5. 기존 데이터 옮기기 (처음 한 번)

`admin.html` 에 로그인한 뒤

- **멤버** 탭 → **기존 멤버 가져오기** (지금 홈페이지의 30명)
- **블로그** 탭 → **기존 글 가져오기**
- **메인 배너** 탭 → **기본 사진 가져오기** (선택)

가져오기 전까지는 홈페이지가 기존 데이터를 그대로 보여 줍니다.

## 관리자 페이지에서 할 수 있는 일

| 탭 | 기능 |
|---|---|
| 문의 | 참관(비지터) 신청 · 협업 문의 확인, 처리 완료 표시, 메모, 삭제 |
| 멤버 | 추가 · 수정 · 숨기기 · 삭제, 프로필 사진 · **명함 이미지** 올리기, **홈페이지 링크**, 등급(골드·그린) · 직급(의장 등), 순서 |
| 블로그 | 글 쓰기 · 수정 · 숨기기 · 삭제 |
| 메인 배너 | 사진 올리기, 순서 바꾸기, 숨기기, 삭제 |
| 일정 | 휴회 · 화상회의 · 행사 날짜 등록 (매주 수요일 조찬회의는 자동) |
| 관리자 계정 | 관리자 이메일 추가 · 삭제 (본인과 마지막 1명은 삭제 불가) |

## 관리자를 더 추가하려면

1. 관리자 페이지 → **관리자 계정** 탭 → 이메일 입력 → **관리자 추가**
2. 추가된 사람이 `admin.html` 에서 **'처음이신가요? 계정 만들기'** 로 같은 이메일 가입

관리자 권한을 삭제하면 그 사람은 로그인해도 관리자 기능을 쓸 수 없어요.

## 문의가 오면 메일·문자로 받기

`알림_설정_안내.md` 를 따라 설정하면 새 문의가 들어올 때 관리자에게 메일과 문자가 바로 갑니다.
