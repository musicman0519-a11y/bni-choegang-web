# 문의 알림 (메일 + 문자) 설정 안내

홈페이지에서 **참관 신청**이나 **협업 문의**가 들어오면 관리자에게 바로 메일과 문자가 갑니다.
먼저 `관리자_설정_안내.md` 의 Supabase 연결이 끝나 있어야 합니다.

```
신청서 제출 → Supabase 저장 → (웹훅) → notify-inquiry 함수 → 메일(Resend) + 문자(SOLAPI)
```

받는 내용 예시

- 문자: `[최강챕터] 새 참관 신청 / 홍길동 010-1234-5678 · Medical / 다음 주 참관하고 싶습니다…`
- 메일: 제목 `[최강챕터] 새 참관 신청 · 홍길동`, 본문에 이름·연락처·이메일·회사·관심 업종·추천인·문의 내용, **관리자 페이지에서 확인하기** 버튼. 메일에서 **답장**하면 신청자에게 바로 갑니다(신청자가 이메일을 적은 경우).

---

## 1. 메일 — Resend (무료, 한 달 3,000통)

1. https://resend.com 가입
2. **API Keys → Create API Key** → 키 복사 (`re_` 로 시작)
3. 보내는 주소 정하기
   - **도메인이 있으면**: **Domains → Add Domain** 에서 도메인 등록 후 안내대로 DNS 설정 → `noreply@내도메인` 으로 누구에게나 발송
   - **도메인이 아직 없으면**: 보내는 주소를 `onboarding@resend.dev` 로 두면 됩니다. 단, 이때는 **Resend 에 가입한 메일 주소로만** 받을 수 있어요.

## 2. 문자 — SOLAPI (건당 약 20원)

1. https://solapi.com 가입 → 충전 (소액 충전 가능)
2. **발신번호 등록**: 보내는 번호(예: 대표 휴대폰)를 등록하고 본인 인증
3. **API Key 관리 → 새 API Key 만들기** → API Key 와 API Secret 복사

> 문자가 45자(한글 기준)를 넘으면 자동으로 장문(LMS, 건당 약 50원)으로 보내져요. 문의 내용은 앞부분 60자까지만 넣습니다.

## 3. 알림 함수 올리기

Supabase 대시보드 → **Edge Functions → Deploy a new function → Via Editor**

1. 함수 이름: `notify-inquiry`
2. 편집기 내용을 지우고 `supabase/functions/notify-inquiry/index.ts` 내용을 전부 붙여넣기 → **Deploy**
3. 함수 설정(Details)에서 **Enforce JWT Verification(=Verify JWT) 끄기**
   → 대신 아래 `WEBHOOK_SECRET` 으로 보호합니다.

## 4. 비밀값(Secrets) 넣기

**Edge Functions → Secrets** 에 하나씩 추가

| 이름 | 값 (예시) |
|---|---|
| `WEBHOOK_SECRET` | 아무 긴 문자열 (예: `choegang-2026-xK29dLq8`) — 5번에서 똑같이 씀 |
| `ADMIN_URL` | `https://내도메인/admin.html` |
| `RESEND_API_KEY` | `re_...` |
| `MAIL_FROM` | `최강챕터 알림 <noreply@내도메인>` (도메인 없으면 넣지 않기) |
| `NOTIFY_EMAILS` | `chair@gmail.com, vice@naver.com` (쉼표로 여러 명) |
| `SOLAPI_API_KEY` | 솔라피 API Key |
| `SOLAPI_API_SECRET` | 솔라피 API Secret |
| `SOLAPI_SENDER` | 등록한 발신번호 `01012345678` |
| `NOTIFY_PHONES` | `01011112222, 01033334444` (쉼표로 여러 명) |

메일만 또는 문자만 쓰고 싶으면 다른 쪽 값은 비워 두면 그 알림만 건너뜁니다.

## 5. 웹훅 연결 (문의가 저장되면 함수 실행)

Supabase 대시보드 → **Database → Webhooks → Create a new hook** (처음이면 Enable webhooks)

| 항목 | 값 |
|---|---|
| Name | `notify-inquiry` |
| Table | `inquiries` |
| Events | **Insert** 만 체크 |
| Type | **Supabase Edge Functions** → `notify-inquiry` 선택 (Method: POST) |
| HTTP Headers | `x-webhook-secret` : 4번의 `WEBHOOK_SECRET` 과 같은 값 |

**Create webhook** 으로 저장하면 끝.

## 6. 시험해 보기

1. 홈페이지 **참관 신청** 페이지에서 시험 신청 보내기
2. 1분 안에 메일·문자가 오는지 확인
3. 안 오면 **Edge Functions → notify-inquiry → Logs** 에서 `메일 실패` / `문자 실패` 메시지 확인
   - `401` : 4번과 5번의 비밀값이 다름
   - 메일 `403` : 도메인 미등록 상태에서 가입 메일이 아닌 주소로 보냄
   - 문자 실패 : 발신번호 미등록 · 잔액 부족 · API 키 오타
4. 시험 신청은 관리자 페이지 **문의** 탭에서 삭제
